Rules

The capital I is always serif. In Segoe UI a capital I and a lowercase l are the same glyph, so “AIvionics” reads as “Alvionics” and the AI disappears. The serif crossbars fix it permanently — including in one-colour print, engraving and fax, where the accent colour is gone.

Never set the name inside the tile. At 32 px it is a smear and at 16 px it is noise; those are the sizes the icon lives at. Windows prints the app name beside the icon anyway.

The blues never change between modes. Sky #8FCBEC → #CFE7F6 and trace #2E9BE0 are identical in light and dark — only the tile and the “vionics” neutral invert. That is what makes them one logo instead of two.

In the app the mark is inline SVG using var(--s1) and var(--txt), so it follows the theme toggle with no second file.

The lockup wordmark is outlined (done 2026-08-09). It was set in Segoe UI Variable Display 28px — A at 800, “vionics” at 600 — with the I in Georgia Bold, letter-spacing −0.3, then converted to paths, so it can no longer re-flow on a machine without those faces. Windows 10 has neither. Its box was tightened from 300×64 to 198×64 at the same time: the old box was 32% empty on the right, which threw the lockup off-centre anywhere it was centred as a whole. Edit the wordmark by re-setting that specification, not by nudging the curves. The square mark files carry no text and are unchanged.
